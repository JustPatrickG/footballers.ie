# Article images

Drop image files here, then set the `image` column in `data/manual/articles.csv`
to `images/your-file.jpg`.

Roughly 1200×675 (16:9) works best. If `image` is blank the article still works —
it just renders without a picture.

Same rule as player photos: only use images you own, have permission for, or that
are properly licensed. Fill in a credit in the article body if the licence needs it.
